After this page you will know what is planned. Nothing on this page exists in the current version.

## Planned

- **First npm release** of `@klawde/tokenwise`. Until then, [run from source](../getting-started/installation/#from-source).
- **Windows verification.** The CI matrix includes Windows; it has not run yet.
- **More harness formats** in discovery and rules: Cursor rules, GitHub Copilot instructions and similar files.

## Under consideration

- Recognizing more retrieval and agent framework configuration formats.
- Additional tokenizer adapters as providers publish offline tokenizers.

Ideas and requests are welcome; see [Contributing](../project/contributing/).
